\apartado{Metodología y requisitos iniciales}
\subsection{Construcción incremental con puertas de salida}
El método sigue dependencias: entorno reproducible, contratos, pruebas de viabilidad y espacio académico. Cada tarea produce artefactos revisables y comprobaciones específicas. Un fallo en una puerta arquitectónica se documenta antes de que otros módulos dependan de ella. Se utiliza un corpus sintético o con licencia para evitar datos privados en pruebas y capturas.

La verificación distingue pruebas unitarias, integración local, navegador y servicios cloud reales. Los proveedores falsos permiten resultados repetibles sin credenciales; se identifican como tales. Una evaluación live de IA se habilita explícitamente y registra modelo, entrada de prueba, latencia y consumo. Una respuesta simulada no valida el proveedor.
